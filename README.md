# Neural Network Playground

ニューラルネットワークの学習過程をブラウザ上でリアルタイム可視化するWebアプリです。
**フレームワーク・外部ライブラリ・ビルドツールを一切使わず**、順伝播・逆伝播・勾配降下法をゼロからJavaScriptで実装しています。

**▶ デモ: https://denidula.github.io/neural-network-playground/**

## 特徴

- **ニューラルネットワーク本体を自前実装** — 順伝播 / 逆伝播 (backpropagation) / ミニバッチSGD / Xavier初期化 / 二値交差エントロピー。すべて [`js/nn.js`](js/nn.js) に日本語コメント付きで実装
- **決定境界のリアルタイム可視化** — 学習が進むにつれて分類境界が変形していく様子を毎フレーム描画
- **ネットワーク図** — ニューロン＝円、重み＝線。線の太さ＝重みの大きさ、色＝正負。各ニューロンの円の中には「そのニューロンが入力空間をどう見ているか」のミニヒートマップを表示。学習中は信号が流れるアニメーション付き
- **損失グラフ** — 学習損失・テスト損失の2本をリアルタイム描画。ノイズを上げると過学習(2本の線の乖離)が観察できる
- **インタラクティブな構造カスタマイズ** — 隠れ層 0〜4層・各層 1〜8ニューロン・活性化関数 (ReLU / tanh / sigmoid)・学習率 (対数スケール 0.001〜1.0)
- **4種類のデータセット** — 2つの円 / XOR / 渦巻き / ガウス。ノイズ量も調整可能
- **初心者向け設計** — 全設定に「?」ホバー解説、ページ下部に機械学習の仕組みの平易な解説を掲載

## 技術構成

| ファイル | 役割 |
|---|---|
| `js/nn.js` | ニューラルネットワーク本体(このプロジェクトの核) |
| `js/data.js` | 2次元分類データセットの生成 |
| `js/netview.js` | ネットワーク図の描画(Canvas) |
| `js/lossview.js` | 損失グラフの描画(Canvas) |
| `js/theme.js` | クラス色・描画フラグの単一情報源 |
| `js/main.js` | 状態管理・学習ループ・決定境界の描画 |

- 純粋な HTML / CSS / JavaScript のみ(依存ゼロ)
- 描画は Canvas API + `requestAnimationFrame`(60fps維持のため、ヒートマップは粗いグリッドで計算し拡大描画・重い再計算はフレーム間引き)
- ES modules 不使用 — `index.html` をダブルクリックするだけでローカル実行可能

## ローカルで動かす

```
git clone https://github.com/Denidula/neural-network-playground.git
```

`index.html` をブラウザで開くだけです。ビルドもサーバーも不要です。

## 遊び方のヒント

1. **隠れ層を0にする** → 直線でしか分類できなくなる(線形モデルの限界)
2. **渦巻き + ReLU + 8ニューロン×2層** → 最難関データセットの攻略
3. **ノイズを0.5に上げる** → 過学習(学習損失とテスト損失の乖離)を観察
4. **学習率を1.0にする** → 学習の暴走を観察
